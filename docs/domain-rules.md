# 领域规则与人工门禁

## 门禁链

创作契约审批 → 规划批准 → 正文生成；关键章/卷界/重大状态变化/事实冲突强制逐章；存在未解决硬性问题不能定稿或进入发布队列。

## 状态机

- 章节：章纲 → 草稿 → 待质检 → 待定稿 → 已定稿 → 待发布 → 已发布（转移规则见 `src/shared/chapter-lifecycle.ts`）。
- 状态值唯一数据源：`src/shared/status-constants.ts`，类型由此派生（见 `types.ts`）。

## 变更单

已审批契约、已批准规划、已定稿/发布中的章节如需修改，必须先批准改纲变更单（版本号 + 快照双重校验）；实际保存后变更单标记为“已应用”。AI 只生成候选、草稿和建议，不会自动定稿、改纲或发布。

## 错误处理

模型层错误用稳定 code 分类（`src/shared/error-codes.ts` 的 `AppError`），中文文案仅作展示，判定逻辑不依赖中文前缀。
